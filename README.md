# Gagan Warade — Portfolio Website

A responsive, single-page portfolio built with HTML and CSS. No build step or dependencies required.

## Preview locally

Open `index.html` in a browser. Keep `assets/Gagan_Warade_Resume.pdf` in place so the resume links work.

## Deploy to Vercel (free)

1. Create a GitHub repository and upload all files in this folder (`index.html`, `README.md`, and `assets/`).
2. Sign in at https://vercel.com/ and choose **Add New → Project**.
3. Import the GitHub repository.
4. For a plain static site, leave the framework preset as **Other**; leave build command and output directory blank/default.
5. Click **Deploy**. Vercel will give you a live `*.vercel.app` URL. You can rename the project in Vercel settings to a suitable available name such as `gagan-warade-portfolio`.

## Before publishing

- Add LinkedIn and GitHub profile URLs if you want them displayed.
- Review the phone numbers and email in `index.html`.
- Confirm that the resume is okay to publish publicly.

The project summaries are intentionally based only on the supplied resume and avoid claiming unlisted metrics or publishing confidential implementation details.
